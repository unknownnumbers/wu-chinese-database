# 八地 IPA 与吴拼读法指南: 共性与差异

[English (en)](common-and-differences.en.md) | [Traditional Chinese (zh-TC)](common-and-differences.md) | [Simplified Chinese (zh-SC)](common-and-differences.zh-SC.md)

本表整理共同声母、单字本调及各数据点的基本韵母与必要分支. 表内只列规则对应, 不包含逐字记录或已见音节证据.

这是一份供人阅读的拼读指南. 先了解拼写、音标与调号怎样分工, 再读共同声母、各地韵母和条件拼式, 最后按演示练习查表. 想查看数据字段和规则选择的精确顺序, 再读[宣告式规则书](rulebook.zh-SC.md). 八份完整条件表见[地区索引](regions.zh-SC.md).

阅读表是合并后的摘要, 并非全部条件的逐列展开. 机器可读的完整条件见 [组件规则](../rules/component-rules.json), 单字本调见 [本调数据](../rules/citation-tones.json). 选择顺序、唯一性与 y/w 起首限制见 [规则书](rulebook.zh-SC.md).

含 y/w 的拼写须在相应起首环境中成立. 表内未写出另一环境的形式时, 不据此补造分支. 没有条件支持时保留未解.

## 先看懂拼写、音标与数据点

八套数据来自昆山老派、苏州、上海老派、上海、嘉兴、无锡、昆山新派及常熟. 它们是六个地点的八套地方数据, 不是八个谱系分支, 也不代表所有吴语共用一套音系. 新老派名称标示数据自身的区分, 不等于所有同龄说话人的一致读法.

吴拼是拼写系统, IPA 栏则保存本套数据所用的记音. 看见同一个吴拼字母, 不应立即套用国语拼音、英语读法或另一地的音值. `oe`、`au`、`eu` 等是完整韵母拼式, 不一定表示依次读出两个元音. 来源记音中的 `ᴀ`、`ᴇ`、`ɿ`、`ʮ`、`ȵ` 和下标 `ⱼ` 均有区别, 本指南不把它们擅自换成另一套精密音标分析.

读一个完整拼式时, 先分辨末尾完整调号, 再辨认声母与韵母. `ph`、`tsh`、`ch`、`ng`、`gn`、`gh` 这些组合要按本地声母分析, 不逐字母念. 例如 `ph` 表示送气的 `pʰ`, 不是先读 p 再多读一个 h 音节. `ng` 通常对应鼻音 `ŋ`, `gn` 对应 `ȵ`, 两者不能混为一音.

韵母中的鼻化、鼻尾与入声也要查完整对应. `an`、`aon` 在这些表中常对应鼻化元音; 其他以 n 结尾的拼式可能对应鼻尾或特定韵类, 不能把每个 n 都读成同一个音. `q` 是入声韵母的一部分, 常对应 `ʔ`; `aq`、`eq`、`iq` 等须整体查, 不能把任一舒声韵母机械加上声门塞音便当成有效入声.

## 单字本调

调号与调值分开. `-` 表示此表未列该地调号, 不是零调值, 也不授权推补. 本表不涵盖连读变调.

吴拼末尾的号码是调类或子类标签. 这套编号以 `1 / 2` 表阴平/阳平、`3 / 4` 表阴上/阳上、`5 / 6` 表阴去/阳去、`7 / 8` 表阴入/阳入. 各地有调类合流, 所以不要求八个号码全部存在. 嘉兴的 `3b` 是另一个完整后缀, 不能把 b 当作韵尾或删去.

IPA 上标是五度调值, `1` 最低、`5` 最高. `⁴⁴` 表示保持在 4 的高度, `¹³²` 表示由 1 升到 3 再降到 2. 调号 `6` 并不表示第六度, 同一个调号在不同地区也不必具有相同调值. 入声栏的单个数字仍是本调调值记法, 不表示一个可以直接与舒声等同时长的音节.

## 清浊与阴阳怎样帮助阅读

正常单字本调的主要搭配倾向是清阻塞音配阴调、浊阻塞音配阳调. 送气清音仍是清音, 不能因为有 h 或 `ʰ` 就当成浊音. 这个倾向可帮助检视, 不能单独决定平、上、去、入, 也不能用来自动更改数据.

| 声母类型 | 常见记号 | 通常查看的非入声调号 | 通常查看的入声调号 |
| --- | --- | --- | --- |
| 清不送气阻塞音及清擦音 | `p`、`t`、`k`、`ts`、`tɕ`、`f`、`s`、`ɕ`、`h` | 本地有列出的 `1`、`3`、`5` | `7` |
| 清送气阻塞音 | `pʰ`、`tʰ`、`kʰ`、`tsʰ`、`tɕʰ` | 仍查看本地阴调 | `7` |
| 浊阻塞音 | `b`、`d`、`ɡ`、`dz`、`dʑ`、`v`、`z`, 上海老派另有 `β` | 本地有列出的 `2`、`4`、`6` | `8` |
| `ɦ` 起首类 | `ɦ`, 拼写可能涉及 `gh`、`y`、`w` | 按本地完整条件查看阳调 | 通常为 `8`, 仍查完整条件 |

只看浊声母 b, 不能在 `2`、`4`、`6` 中任选一个. 鼻音和边音等响音也不等于浊阻塞音, 可以有阴调或阳调, 不能一律只配偶数号. 真正零声母及 y/w 拼写须回到本地结构和发声态条件, 不由第一个拉丁字母派调.

阴调和阳调不是两条跨地通用的音高曲线. 阴调某个时间点不一定高于阳调的每个时间点, 所以不能拿曲线中某一个数字判阴阳. 入声虽常有 `ʔ` 韵尾, 阴阳也不由这个共同韵尾决定. 已明列的少数反向搭配仍保留, 后面的演示列出具体组件条件, 不把它们扩成新通则.

## gh、y、w 与真正零声母

先确定完整音节有没有 `ɦ`, 再看本地基本韵母. 在有支持的条件中, ɦ 加 i/y 类起首韵母常形成 y 拼式, 加 u 类常形成 w 拼式; 其他组合可能仍写 gh. 这是条件拼写, 不能全局删掉 ɦ, 也不能见到零声母就加 y/w.

常见的拼式家族包括 `i → yi`、`ia → ya`、`ioe → yoe`、`iu → yu`、`u → wu`、`ue → we`. 这些只是帮助辨认的家族, 不保证每地都有每一格. 昆山老派的零声母 i 分支输出 i, ɦ 加 i 的分支输出 yi; 同地 ɦ 加 a 仍有 gh+a 的分支. 不能据此替上海老派或另一套数据补出未列条件.

反过来, y/w 拼式也不保证一定要还原成 ɦ. 苏州表另保存 `wɑ → wa`、`yaʔ → yuaeq` 这类不同记音结构. 人工阅读时先核对本地完整条件, 不由拼式首字母强迫所有候选合为一个音.

精确的正向选择还有一项限制: 即使通用 `final` 层只剩一个 y/w 起首输出, 也须继续查对应的 `final_environment` 或 `final_onset` 层. 例如舌尖类韵母输出的 y/yu 也要符合环境条件, 不能因本指南的拼式概括而省掉这一步.

## y、yu、gn 与成音节音

吴拼中的 y 不能一律念成 IPA 的 `y`. 在昆山老派的普通辅音环境, `ɿ → y`、`ʮ → yu`、IPA 元音 `y → iu` 是三种不同对应. 苏州还要区分 `y → ieu` 与 `yⱼ → iu`. 完整音节的 yu 又可能涉及 ɦ 起首, 不能只凭这两个字母认作 `ʮ`.

把 `gnie6` 分成 `gn + ie + 6`, 不分成 g+n+i+e. gn 是一个声母拼式, ie 是完整韵母. gni 开头不表示要在声母之外多读一个独立 i 音节. `ȵ` 和 `ŋ` 保持分立, 不把 gn 和 ng 当作可自由互换.

`m`、`n`、`ng` 有时本身就是成音节音, 嘉兴另有 l. 记音可能明写成节符, 也可能直接在响音后附调值. 不能因找不到普通元音便说漏了韵母, 也不能把所有一般鼻音声母都当成成音节音. 嘉兴的 l 不改成别地的 er; er 也不跨地同音, 本表可见 əl、ɚ、ər, 昆山新派另有 el. 无锡 `ɦ + ŋ` 的组件也不机械拼成 ghng.

## 怎样手工查一个完整拼式

1. 选定数据点和新老派, 不跨表借音值.
2. 先认出完整调号后缀, 特别保留嘉兴 3b.
3. 区分普通声韵结构、真正零声母、ɦ 相关拼式与成音节音.
4. 把多字母声母视为完整拼写单位, 再查整个本地韵母, 不逐字母转码.
5. 套入有明确条件的分支, 如苏州下标、常熟龈腭/卷舌组、起首环境和 y/w 拼式.
6. 按本地调号查本调值, 再核对入声、清浊和发声态条件. 清浊只提供部分线索, 不代替完整调类.
7. 反向有多个组合或缺少条件时保留未解. 即使组件唯一, 仍不能把它宣称为某个字已证实的读音.

这是人工查表的阅读路线, 不是本库已提供的解析程序. 正向的逐层唯一性选择和反向回验细节仍依[宣告式规则书](rulebook.zh-SC.md).

## 使用范围

相同吴拼字母不保证跨地区具有相同 IPA. 成节音、鼻化音、下标与地方元音记号均依数据原有区别保留. 韵母表中的条件分支不授权跨环境移用, 也不能直接产生未列出的完整音节.

本次只发布宣告式规则和规则书, 没有独立解析器、转换器或已见音节清单. 本次未重跑历史语料回归.
