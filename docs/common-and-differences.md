# 八地 IPA 與吳拼的共性與差異

本表整理共同聲母、單字本調及各資料點的基本韻母與必要分支. 表內只列規則對應, 不包含逐字記錄或已見音節證據.

閱讀表是合併後的摘要, 並非全部條件的逐列展開. 機器可讀的完整條件見 [組件規則](../rules/component-rules.json), 單字本調見 [本調資料](../rules/citation-tones.json). 選擇順序、唯一性與 y/w 起首限制見 [規則書](rulebook.md).

含 y/w 的拼寫須在相應起首環境中成立. 表內未寫出另一環境的形式時, 不據此補造分支. 沒有條件支持時保留未解.

## 使用範圍

相同吳拼字母不保證跨地區具有相同 IPA. 成節音、鼻化音、下標與地方元音記號均依資料原有區別保留. 韻母表中的條件分支不授權跨環境移用, 也不能直接產生未列出的完整音節.

本次只發布宣告式規則和規則書, 沒有獨立解析器、轉換器或已見音節清單. 本次未重跑歷史語料回歸.
