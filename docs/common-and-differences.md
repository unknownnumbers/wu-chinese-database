# 八地 IPA 與吳拼讀法指南: 共性與差異

[English (en)](common-and-differences.en.md) | [Traditional Chinese (zh-TC)](common-and-differences.md) | [Simplified Chinese (zh-SC)](common-and-differences.zh-SC.md)

本表整理共同聲母、單字本調及各資料點的基本韻母與必要分支. 表內只列規則對應, 不包含逐字記錄或已見音節證據.

這是一份供人閱讀的拼讀指南. 先了解拼寫、音標與調號怎樣分工, 再讀共同聲母、各地韻母和條件拼式, 最後按演示練習查表. 想查看資料欄位和規則選擇的精確順序, 再讀[宣告式規則書](rulebook.md). 八份完整條件表見[地區索引](regions.md).

閱讀表是合併後的摘要, 並非全部條件的逐列展開. 機器可讀的完整條件見 [組件規則](../rules/component-rules.json), 單字本調見 [本調資料](../rules/citation-tones.json). 選擇順序、唯一性與 y/w 起首限制見 [規則書](rulebook.md).

含 y/w 的拼寫須在相應起首環境中成立. 表內未寫出另一環境的形式時, 不據此補造分支. 沒有條件支持時保留未解.

## 先看懂拼寫、音標與資料點

八套資料來自崑山老派、蘇州、上海老派、上海、嘉興、無錫、崑山新派及常熟. 它們是六個地點的八套地方資料, 不是八個譜系分支, 也不代表所有吳語共用一套音系. 新老派名稱標示資料自身的區分, 不等於所有同齡說話人的一致讀法.

吳拼是拼寫系統, IPA 欄則保存本套資料所用的記音. 看見同一個吳拼字母, 不應立即套用國語拼音、英語讀法或另一地的音值. `oe`、`au`、`eu` 等是完整韻母拼式, 不一定表示依次讀出兩個元音. 來源記音中的 `ᴀ`、`ᴇ`、`ɿ`、`ʮ`、`ȵ` 和下標 `ⱼ` 均有區別, 本指南不把它們擅自換成另一套精密音標分析.

讀一個完整拼式時, 先分辨末尾完整調號, 再辨認聲母與韻母. `ph`、`tsh`、`ch`、`ng`、`gn`、`gh` 這些組合要按本地聲母分析, 不逐字母念. 例如 `ph` 表示送氣的 `pʰ`, 不是先讀 p 再多讀一個 h 音節. `ng` 通常對應鼻音 `ŋ`, `gn` 對應 `ȵ`, 兩者不能混為一音.

韻母中的鼻化、鼻尾與入聲也要查完整對應. `an`、`aon` 在這些表中常對應鼻化元音; 其他以 n 結尾的拼式可能對應鼻尾或特定韻類, 不能把每個 n 都讀成同一個音. `q` 是入聲韻母的一部分, 常對應 `ʔ`; `aq`、`eq`、`iq` 等須整體查, 不能把任一舒聲韻母機械加上聲門塞音便當成有效入聲.

## 單字本調

調號與調值分開. `-` 表示此表未列該地調號, 不是零調值, 也不授權推補. 本表不涵蓋連讀變調.

吳拼末尾的號碼是調類或子類標籤. 這套編號以 `1 / 2` 表陰平/陽平、`3 / 4` 表陰上/陽上、`5 / 6` 表陰去/陽去、`7 / 8` 表陰入/陽入. 各地有調類合流, 所以不要求八個號碼全部存在. 嘉興的 `3b` 是另一個完整後綴, 不能把 b 當作韻尾或刪去.

IPA 上標是五度調值, `1` 最低、`5` 最高. `⁴⁴` 表示保持在 4 的高度, `¹³²` 表示由 1 升到 3 再降到 2. 調號 `6` 並不表示第六度, 同一個調號在不同地區也不必具有相同調值. 入聲欄的單個數字仍是本調調值記法, 不表示一個可以直接與舒聲等同時長的音節.

## 清濁與陰陽怎樣幫助閱讀

正常單字本調的主要搭配傾向是清阻塞音配陰調、濁阻塞音配陽調. 送氣清音仍是清音, 不能因為有 h 或 `ʰ` 就當成濁音. 這個傾向可幫助檢視, 不能單獨決定平、上、去、入, 也不能用來自動更改資料.

| 聲母類型 | 常見記號 | 通常查看的非入聲調號 | 通常查看的入聲調號 |
| --- | --- | --- | --- |
| 清不送氣阻塞音及清擦音 | `p`、`t`、`k`、`ts`、`tɕ`、`f`、`s`、`ɕ`、`h` | 本地有列出的 `1`、`3`、`5` | `7` |
| 清送氣阻塞音 | `pʰ`、`tʰ`、`kʰ`、`tsʰ`、`tɕʰ` | 仍查看本地陰調 | `7` |
| 濁阻塞音 | `b`、`d`、`ɡ`、`dz`、`dʑ`、`v`、`z`, 上海老派另有 `β` | 本地有列出的 `2`、`4`、`6` | `8` |
| `ɦ` 起首類 | `ɦ`, 拼寫可能涉及 `gh`、`y`、`w` | 按本地完整條件查看陽調 | 通常為 `8`, 仍查完整條件 |

只看濁聲母 b, 不能在 `2`、`4`、`6` 中任選一個. 鼻音和邊音等響音也不等於濁阻塞音, 可以有陰調或陽調, 不能一律只配偶數號. 真正零聲母及 y/w 拼寫須回到本地結構和發聲態條件, 不由第一個拉丁字母派調.

陰調和陽調不是兩條跨地通用的音高曲線. 陰調某個時間點不一定高於陽調的每個時間點, 所以不能拿曲線中某一個數字判陰陽. 入聲雖常有 `ʔ` 韻尾, 陰陽也不由這個共同韻尾決定. 已明列的少數反向搭配仍保留, 後面的演示列出具體組件條件, 不把它們擴成新通則.

## gh、y、w 與真正零聲母

先確定完整音節有沒有 `ɦ`, 再看本地基本韻母. 在有支持的條件中, ɦ 加 i/y 類起首韻母常形成 y 拼式, 加 u 類常形成 w 拼式; 其他組合可能仍寫 gh. 這是條件拼寫, 不能全局刪掉 ɦ, 也不能見到零聲母就加 y/w.

常見的拼式家族包括 `i → yi`、`ia → ya`、`ioe → yoe`、`iu → yu`、`u → wu`、`ue → we`. 這些只是幫助辨認的家族, 不保證每地都有每一格. 崑山老派的零聲母 i 分支輸出 i, ɦ 加 i 的分支輸出 yi; 同地 ɦ 加 a 仍有 gh+a 的分支. 不能據此替上海老派或另一套資料補出未列條件.

反過來, y/w 拼式也不保證一定要還原成 ɦ. 蘇州表另保存 `wɑ → wa`、`yaʔ → yuaeq` 這類不同記音結構. 人工閱讀時先核對本地完整條件, 不由拼式首字母強迫所有候選合為一個音.

精確的正向選擇還有一項限制: 即使通用 `final` 層只剩一個 y/w 起首輸出, 也須繼續查對應的 `final_environment` 或 `final_onset` 層. 例如舌尖類韻母輸出的 y/yu 也要符合環境條件, 不能因本指南的拼式概括而省掉這一步.

## y、yu、gn 與成音節音

吳拼中的 y 不能一律念成 IPA 的 `y`. 在崑山老派的普通輔音環境, `ɿ → y`、`ʮ → yu`、IPA 元音 `y → iu` 是三種不同對應. 蘇州還要區分 `y → ieu` 與 `yⱼ → iu`. 完整音節的 yu 又可能涉及 ɦ 起首, 不能只憑這兩個字母認作 `ʮ`.

把 `gnie6` 分成 `gn + ie + 6`, 不分成 g+n+i+e. gn 是一個聲母拼式, ie 是完整韻母. gni 開頭不表示要在聲母之外多讀一個獨立 i 音節. `ȵ` 和 `ŋ` 保持分立, 不把 gn 和 ng 當作可自由互換.

`m`、`n`、`ng` 有時本身就是成音節音, 嘉興另有 l. 記音可能明寫成節符, 也可能直接在響音後附調值. 不能因找不到普通元音便說漏了韻母, 也不能把所有一般鼻音聲母都當成成音節音. 嘉興的 l 不改成別地的 er; er 也不跨地同音, 本表可見 əl、ɚ、ər, 崑山新派另有 el. 無錫 `ɦ + ŋ` 的組件也不機械拼成 ghng.

## 怎樣手工查一個完整拼式

1. 選定資料點和新老派, 不跨表借音值.
2. 先認出完整調號後綴, 特別保留嘉興 3b.
3. 區分普通聲韻結構、真正零聲母、ɦ 相關拼式與成音節音.
4. 把多字母聲母視為完整拼寫單位, 再查整個本地韻母, 不逐字母轉碼.
5. 套入有明確條件的分支, 如蘇州下標、常熟齦腭/捲舌組、起首環境和 y/w 拼式.
6. 按本地調號查本調值, 再核對入聲、清濁和發聲態條件. 清濁只提供部分線索, 不代替完整調類.
7. 反向有多個組合或缺少條件時保留未解. 即使組件唯一, 仍不能把它宣稱為某個字已證實的讀音.

這是人工查表的閱讀路線, 不是本庫已提供的解析程式. 正向的逐層唯一性選擇和反向回驗細節仍依[宣告式規則書](rulebook.md).

## 使用範圍

相同吳拼字母不保證跨地區具有相同 IPA. 成節音、鼻化音、下標與地方元音記號均依資料原有區別保留. 韻母表中的條件分支不授權跨環境移用, 也不能直接產生未列出的完整音節.
