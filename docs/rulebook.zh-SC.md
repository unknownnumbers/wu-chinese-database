# IPA 与吴拼宣告式规则书

[English (en)](rulebook.en.md) | [Traditional Chinese (zh-TC)](rulebook.md) | [Simplified Chinese (zh-SC)](rulebook.zh-SC.md)

本次发布八个地区及新老派数据点的 IPA 与吴拼组件规则、单字本调对照和阅读说明. 转换对象是指定地区的语音结构, 字头、字义和国语读音不参与规则选择.

本库提供宣告式数据与规则书. 本次没有提供可独立执行的 IPA 解析器或双向转换器, 也没有提供已见音节清单 (attested inventory). 下文描述数据的含义与规则选择方式, 不能视为本库已具备相应执行能力.

## 数据入口

- [组件规则](../rules/component-rules.json): 声母、韵母、起首环境及声调条件.
- [单字本调表](../rules/citation-tones.json): 各数据点的吴拼调号与本调调值.
- [共性与差异](common-and-differences.zh-SC.md): 共同声母、本调和各地韵母的阅读摘要.

组件规则保存全部条件及其可能输出. 某条件有多个输出时, 数据保留这项冲突, 不以出现次数选一个答案. 阅读摘要则是经选择与合并的有效条件视图, 不能当作全部规则的逐列展开, 也不能取代规则的选择顺序.

## 规则记录与条件字段

每条组件规则使用 `family`、`condition` 和 `outputs` 表示. `condition` 是依固定位置排列的数组, `outputs` 中每个 `value` 是一个不同的可能输出. 声韵 family 的输出是吴拼组件, `tone` 的输出是吴拼调号后缀.

下表以 `table_id` 表示地区 ID, 以 `register` 表示数据中的分类标签. 两者是每种条件的前两项.

| family | condition 的位置顺序 | 输出含义 |
| --- | --- | --- |
| `onset` | `[table_id, register, onset]` | 吴拼声母 |
| `onset_final` | `[table_id, register, onset, final]` | 指定后接韵母时的吴拼声母 |
| `final` | `[table_id, register, final]` | 吴拼韵母 |
| `final_environment` | `[table_id, register, final, environment]` | 指定起首环境时的吴拼韵母 |
| `final_onset` | `[table_id, register, final, onset]` | 指定 IPA 声母时的吴拼韵母 |
| `tone` | `[table_id, register, pitch, checked, voicing, phonation]` | 吴拼调号后缀 |

`onset` 和 `final` 条件中的字符串是分解后的 IPA 组件, 不是汉字或完整词条. `pitch` 是调值字符串, 例如 `"44"`, 与表示调类的吴拼后缀 `"1"` 分开.

目前的 `register` 标签为 `default` 和 `ordinary`. 它们是条件的一部分, 不等于可自行推导的阴阳调类、文白层次或说话人年龄. 实现须明确建立输入与这些分类的对应, 不能在分类未明时任填一项.

本次宣告中的苏州条件使用 `ordinary`, 其余七个数据点使用 `default`. 这项标签分布不表示任意未解析音节均可自动归类.

起首环境 `environment` 有以下三值.

| 值 | 条件 |
| --- | --- |
| `zero` | IPA 声母为空字符串 |
| `breathy_h` | IPA 声母恰为 `ɦ` |
| `consonant` | 其余非空声母 |

`checked` 是 JSON 布尔值, 表示是否为入声结构. `voicing` 的现有值为 `sonorant`、`voiced_obstruent`、`voiceless_obstruent` 和 `zero`. `phonation` 的现有值为 `modal_or_unmarked`. 这些标签须由明确的解析与分类方式产生, 本次数据没有附带该解析器.

## 空值与无法判定

声母位置的空字符串 `""` 表示零声母. 声母输出的空字符串也可以是有效输出, 不应视为没有规则. 阅读表使用 `∅` 帮助显示, JSON 比对仍使用实际字符串.

缺少规则、条件字段缺失、无法解析和合法的空字符串是不同情况. 未提供的调值不能补成零调或任一调号. 本次数据不包含逐条未标调配对, 不能以历史上曾保留未标调用法为由声称本库可以还原它们.

## 正向规则选择

下列是数据所对应的选择方式, 供另行实现时使用. 每一步都须使用同一地区、同一分类下的完整条件.

1. 明确分解 IPA 声母、韵母、本调调值、入声属性、清浊类别与发声态. 无法建立这些必要特征时停止, 保留未解状态.
2. 声母先查 `onset`, 没有唯一输出时再查 `onset_final`.
3. 韵母先查 `final`, 再按需要查 `final_environment`, 最后查 `final_onset`. 下节的 y/w 限制也会使通用层跳至环境层.
4. 声调只查完整条件的 `tone`, 不从声母字母或其他地区补调.
5. 每个组件均有唯一有效输出后, 才能拼接吴拼声母、韵母和调号后缀. 再检查拼写结构和本调对照.

在任一层, 输出集合恰有一个不同值才是唯一. 没有值表示该层未覆盖, 多于一个表示该层冲突. 可以依上述顺序缩小条件, 但最后仍不唯一时必须返回未解, 不取多数、第一个值或最常见拼写.

唯一通则已适用时, 不再把后续更细条件的所有输出累加成候选. `rulebook` 的全部宣告中可以同时存在通用层的冲突与细分层的唯一结果. 将所有匹配列直接并集, 与按顺序选择规则的含义不同.

## y/w 起首环境限制

吴拼的 y/w 拼写可能涉及声母与韵母的共同环境. 不能仅因某个韵母在一处拼 y/w, 就把同样拼写搬到另一类起首环境.

若通用 `final` 层唯一输出以 `y` 或 `w` 开头, 仍须跳过该通用结果, 继续查相同输入的 `final_environment`, 必要时再查 `final_onset`. 只有环境层或指定声母层的唯一结果才可采用. 找不到相应唯一条件时, 保留未解.

这项限制不表示所有 `y` 或 `w` 都必然代表 `ɦ`, 也不表示见到零声母就补 y/w. 韵母自身的拼写和起首环境都要按条件处理. `ɦ` 也可能输出 `gh` 或空声母, 不能全局删除或一律改写为 `gh`.

## 单字本调约束

[单字本调表](../rules/citation-tones.json) 将吴拼调号后缀映射至各数据点的固定本调调值. 调号是分类编号, 不是五度调值数字. 嘉兴的 `3b` 是完整后缀, 不能删去 `b` 或并入 `3`.

组件声调规则与本调表须同时满足. 有完整调号与调值时, 检查该后缀是否存在及调值是否吻合. 只有一侧有调值或调号、后缀未列入本地表、或两侧对应不合时, 应报出未解或冲突, 不自动修正原输入.

清阻塞音与阴调、浊阻塞音与阳调的关系可帮助检视, 但不能单独决定平上去入. 响音也不能只按奇偶调号分派. 规则明列的入声、清浊和发声态条件仍须逐项匹配.

入声属性须与声韵结构及拼写相容. 不能只因调值数字相同, 就把入声与非入声条件互换.

这套本调表的范围是单字本调, 不适用于连读变调、轻读、合音或任意多字词. 不从一地调号推定另一地音高, 也不凭反向对应补造未提供的调类.

## 符号与解析边界

IPA 组件按宣告字符串区分. `a` 与 `ɑ`、`ã` 与 `ɑ̃`、`iə` 与 `ə`、`i` 与 `iⱼ`、`y` 与 `yⱼ` 均不可全局混同. `ɸ` 与 `f`、`β` 与 `v` 也不能只当作字形别名. 发音记号中的下标、送气符和成节符均可能参与识别.

本次机器数据的浊软颚塞音声母键使用普通字符 `g`, 阅读表则以 IPA 字形 `ɡ` 显示. 这是数据键与展示记号的区别. 本次没有附带接受两种输入并自动规范化的执行器, 不应把展示字形直接当作机器键.

数字上标与普通数字之间的表示转换, 必须与调值解析分开. 字符规范化不等于音系合并. 另行实现须公开其接受的符号、拆分方式和分类方式, 不能把本库当作已包含这些步骤的完整解析规范.

## 反向候选与 attested 的区别

反向设计可先逆用声母、韵母和声调组件, 枚举同地区与同分类下的组合, 再用完整正向条件回验. 只有正向回验恰好得到原吴拼的组合, 才能保留为规则可组成的候选.

组件可组成、正向可回验和实际已有读音记录是三件事. 只有另行取得授权清楚、来源可追溯的已见音节清单, 并按地区与完整 IPA/吴拼配对过滤后, 才能称为 `attested`. 候选只有一个也不构成已见证据.

本次没有提供该清单, 也没有反向执行器. 因此本库不能独立提供已见音节过滤、逐字查音或实际读音认定. 未见组合只可作待查的规则候选.

## 本次能力与验证范围

本次成果是可阅读、可机器读取的宣告式规则数据与原创整理说明. 规则书所述选择顺序是实现要求, 不表示已发布转换程序.

本次没有重新执行历史语料回归, 也没有重新核实原站每条读音. 本轮若有 JSON 结构、文件完整性或数据一致性检查, 其通过不等于未知音节均可推导、反向候选均已见、或所有音值均获独立证明.

完整解析器、可执行转换器、具有清楚授权的已见音节清单及公开语料回归, 均属需另行完成的工作, 不列入本次既有能力.
