# IPA 與吳拼宣告式規則書

本次發布八個地區及新老派資料點的 IPA 與吳拼組件規則、單字本調對照和閱讀說明. 轉換對象是指定地區的語音結構, 字頭、字義和國語讀音不參與規則選擇.

本庫提供宣告式資料與規則書. 本次沒有提供可獨立執行的 IPA 解析器或雙向轉換器, 也沒有提供已見音節清單 (attested inventory). 下文描述資料的含義與規則選擇方式, 不能視為本庫已具備相應執行能力.

## 資料入口

- [組件規則](../rules/component-rules.json): 聲母、韻母、起首環境及聲調條件.
- [單字本調表](../rules/citation-tones.json): 各資料點的吳拼調號與本調調值.
- [共性與差異](common-and-differences.md): 共同聲母、本調和各地韻母的閱讀摘要.

組件規則保存全部條件及其可能輸出. 某條件有多個輸出時, 資料保留這項衝突, 不以出現次數選一個答案. 閱讀摘要則是經選擇與合併的有效條件視圖, 不能當作全部規則的逐列展開, 也不能取代規則的選擇順序.

## 規則記錄與條件欄位

每條組件規則使用 `family`、`condition` 和 `outputs` 表示. `condition` 是依固定位置排列的陣列, `outputs` 中每個 `value` 是一個不同的可能輸出. 聲韻 family 的輸出是吳拼組件, `tone` 的輸出是吳拼調號後綴.

下表以 `table_id` 表示地區 ID, 以 `register` 表示資料中的分類標籤. 兩者是每種條件的前兩項.

| family | condition 的位置順序 | 輸出含義 |
| --- | --- | --- |
| `onset` | `[table_id, register, onset]` | 吳拼聲母 |
| `onset_final` | `[table_id, register, onset, final]` | 指定後接韻母時的吳拼聲母 |
| `final` | `[table_id, register, final]` | 吳拼韻母 |
| `final_environment` | `[table_id, register, final, environment]` | 指定起首環境時的吳拼韻母 |
| `final_onset` | `[table_id, register, final, onset]` | 指定 IPA 聲母時的吳拼韻母 |
| `tone` | `[table_id, register, pitch, checked, voicing, phonation]` | 吳拼調號後綴 |

`onset` 和 `final` 條件中的字串是分解後的 IPA 組件, 不是漢字或完整詞條. `pitch` 是調值字串, 例如 `"44"`, 與表示調類的吳拼後綴 `"1"` 分開.

目前的 `register` 標籤為 `default` 和 `ordinary`. 它們是條件的一部分, 不等於可自行推導的陰陽調類、文白層次或說話人年齡. 實作須明確建立輸入與這些分類的對應, 不能在分類未明時任填一項.

本次宣告中的蘇州條件使用 `ordinary`, 其餘七個資料點使用 `default`. 這項標籤分布不表示任意未解析音節均可自動歸類.

起首環境 `environment` 有以下三值.

| 值 | 條件 |
| --- | --- |
| `zero` | IPA 聲母為空字串 |
| `breathy_h` | IPA 聲母恰為 `ɦ` |
| `consonant` | 其餘非空聲母 |

`checked` 是 JSON 布林值, 表示是否為入聲結構. `voicing` 的現有值為 `sonorant`、`voiced_obstruent`、`voiceless_obstruent` 和 `zero`. `phonation` 的現有值為 `modal_or_unmarked`. 這些標籤須由明確的解析與分類方式產生, 本次資料沒有附帶該解析器.

## 空值與無法判定

聲母位置的空字串 `""` 表示零聲母. 聲母輸出的空字串也可以是有效輸出, 不應視為沒有規則. 閱讀表使用 `∅` 幫助顯示, JSON 比對仍使用實際字串.

缺少規則、條件欄位缺失、無法解析和合法的空字串是不同情況. 未提供的調值不能補成零調或任一調號. 本次資料不包含逐條未標調配對, 不能以歷史上曾保留未標調用法為由聲稱本庫可以還原它們.

## 正向規則選擇

下列是資料所對應的選擇方式, 供另行實作時使用. 每一步都須使用同一地區、同一分類下的完整條件.

1. 明確分解 IPA 聲母、韻母、本調調值、入聲屬性、清濁類別與發聲態. 無法建立這些必要特徵時停止, 保留未解狀態.
2. 聲母先查 `onset`, 沒有唯一輸出時再查 `onset_final`.
3. 韻母先查 `final`, 再按需要查 `final_environment`, 最後查 `final_onset`. 下節的 y/w 限制也會使通用層跳至環境層.
4. 聲調只查完整條件的 `tone`, 不從聲母字母或其他地區補調.
5. 每個組件均有唯一有效輸出後, 才能串接吳拼聲母、韻母和調號後綴. 再檢查拼寫結構和本調對照.

在任一層, 輸出集合恰有一個不同值才是唯一. 沒有值表示該層未覆蓋, 多於一個表示該層衝突. 可以依上述順序縮小條件, 但最後仍不唯一時必須返回未解, 不取多數、第一個值或最常見拼寫.

唯一通則已適用時, 不再把後續更細條件的所有輸出累加成候選. `rulebook` 的全部宣告中可以同時存在通用層的衝突與細分層的唯一結果. 將所有匹配列直接聯集, 與按順序選擇規則的含義不同.

## y/w 起首環境限制

吳拼的 y/w 拼寫可能涉及聲母與韻母的共同環境. 不能僅因某個韻母在一處拼 y/w, 就把同樣拼寫搬到另一類起首環境.

若通用 `final` 層唯一輸出以 `y` 或 `w` 開頭, 仍須跳過該通用結果, 繼續查相同輸入的 `final_environment`, 必要時再查 `final_onset`. 只有環境層或指定聲母層的唯一結果才可採用. 找不到相應唯一條件時, 保留未解.

這項限制不表示所有 `y` 或 `w` 都必然代表 `ɦ`, 也不表示見到零聲母就補 y/w. 韻母自身的拼寫和起首環境都要按條件處理. `ɦ` 也可能輸出 `gh` 或空聲母, 不能全局刪除或一律改寫為 `gh`.

## 單字本調約束

[單字本調表](../rules/citation-tones.json) 將吳拼調號後綴映射至各資料點的固定本調調值. 調號是分類編號, 不是五度調值數字. 嘉興的 `3b` 是完整後綴, 不能刪去 `b` 或併入 `3`.

組件聲調規則與本調表須同時滿足. 有完整調號與調值時, 檢查該後綴是否存在及調值是否吻合. 只有一側有調值或調號、後綴未列入本地表、或兩側對應不合時, 應報出未解或衝突, 不自動修正原輸入.

清阻塞音與陰調、濁阻塞音與陽調的關係可幫助檢視, 但不能單獨決定平上去入. 響音也不能只按奇偶調號分派. 規則明列的入聲、清濁和發聲態條件仍須逐項匹配.

入聲屬性須與聲韻結構及拼寫相容. 不能只因調值數字相同, 就把入聲與非入聲條件互換.

這套本調表的範圍是單字本調, 不適用於連讀變調、輕讀、合音或任意多字詞. 不從一地調號推定另一地音高, 也不憑反向對應補造未提供的調類.

## 符號與解析邊界

IPA 組件按宣告字串區分. `a` 與 `ɑ`、`ã` 與 `ɑ̃`、`iə` 與 `ə`、`i` 與 `iⱼ`、`y` 與 `yⱼ` 均不可全局混同. `ɸ` 與 `f`、`β` 與 `v` 也不能只當作字形別名. 發音記號中的下標、送氣符和成節符均可能參與識別.

本次機器資料的濁軟顎塞音聲母鍵使用普通字元 `g`, 閱讀表則以 IPA 字形 `ɡ` 顯示. 這是資料鍵與展示記號的區別. 本次沒有附帶接受兩種輸入並自動正規化的執行器, 不應把展示字形直接當作機器鍵.

數字上標與普通數字之間的表示轉換, 必須與調值解析分開. 字元正規化不等於音系合併. 另行實作須公開其接受的符號、拆分方式和分類方式, 不能把本庫當作已包含這些步驟的完整解析規範.

## 反向候選與 attested 的區別

反向設計可先逆用聲母、韻母和聲調組件, 枚舉同地區與同分類下的組合, 再用完整正向條件回驗. 只有正向回驗恰好得到原吳拼的組合, 才能保留為規則可組成的候選.

組件可組成、正向可回驗和實際已有讀音記錄是三件事. 只有另行取得授權清楚、來源可追溯的已見音節清單, 並按地區與完整 IPA/吳拼配對過濾後, 才能稱為 `attested`. 候選只有一個也不構成已見證據.

本次沒有提供該清單, 也沒有反向執行器. 因此本庫不能獨立提供已見音節過濾、逐字查音或實際讀音認定. 未見組合只可作待查的規則候選.

## 本次能力與驗證範圍

本次成果是可閱讀、可機器讀取的宣告式規則資料與原創整理說明. 規則書所述選擇順序是實作要求, 不表示已發布轉換程式.

本次沒有重新執行歷史語料回歸, 也沒有重新核實原站每條讀音. 本輪若有 JSON 結構、檔案完整性或資料一致性檢查, 其通過不等於未知音節均可推導、反向候選均已見、或所有音值均獲獨立證明.

完整解析器、可執行轉換器、具有清楚授權的已見音節清單及公開語料回歸, 均屬需另行完成的工作, 不列入本次既有能力.
